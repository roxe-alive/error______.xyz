# **App Name**: Static Echoes

## Core Features:

- Sad Cat Identity: Customizable profile header for error_____.xyz featuring a melancholic cat display picture with high-contrast Neubrutalist framing.
- Thought Sticky Wall: An interactive surface where users can pin 'Sticky Note' style thoughts that persist across sessions, mimicking a physical desktop.
- Lyric Typewriter Machine: A focused animation module that renders provided lyrics with a rhythmic typewriter effect and digital glitch transitions.
- Neubrutalist Navigation: Raw, bold layout components featuring oversized borders and offset shadows typical of modern error-page aesthetics.
- Persistent Sticky Storage: A database-driven system to save and retrieve user thoughts and sticky note placements.

## Style Guidelines:

- Primary Background: Stark White (#FFFFFF) to serve as a high-contrast canvas.
- Accent Colors: Vibrant Yellow (#FFFF00), Bold Blue (#2563EB), and Intense Red (#EF4444) for primary UI elements and sticky notes.
- Border Color: Solid Black (#000000) for all outlines and hard shadows.
- Headline font: 'Space Grotesk' for a computerized, techy aesthetic; paired with 'Source Code Pro' as a monospaced code font for typewriter lyrics.
- A high-contrast grid system with thick 4px black borders on all interactive elements, prioritizing bold outlines and zero blur on shadows.
- Hard-step animations including a 'glitch' cursor for lyric text and snappy 'pop-up' movements for sticky notes.
- Simplistic 2D icons using heavy 3px strokes, matching the raw, unfiltered 'error_____.xyz' vibe.
